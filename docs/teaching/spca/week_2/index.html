Endianness#

Task: Write a function that checks if your system is big or little endian

Possible implementation:

bool is_little_endian() {
    int x = 1; // stored either as [ 01 - 00 - 00 - 00 ]
               //                  ^                   ^
               //                  &x                  &x + 1
    return *((char*)&x);
}

If the system is little endian, the byte `0x01` will be stored at the *lower* end of the memory region where `x` is stored. If it is big-endian, it will be stored at the end of the memory region (ie at (&x + 3 bytes, &x + 4 bytes))
